## Your Task

Optimize this mirrored page to improve:
- **LCP** (Largest Contentful Paint) — time until main content loads
- **CLS** (Cumulative Layout Shift) — visual stability
- **INP** (Interaction to Next Paint) — responsiveness

## Rules

- Do NOT add a build system, bundler, or compilation step
- Do NOT remove visible content or change layout
- Do NOT introduce new external dependencies (no CDN calls)
- Only edit files that already exist in this directory
- Asset paths must stay valid (relative paths are already rewritten)

## Allowed optimizations

- Inline critical CSS into index.html `<style>` blocks
- Defer or async non-critical `<script>` tags
- Add `loading="lazy"` to below-the-fold images
- Add explicit `width`/`height` to images to prevent CLS
- Compress or replace images in assets/img/ with smaller equivalents
- Remove unused CSS from stylesheet files
- Add `font-display: swap` to @font-face rules
- Preload the LCP element's resource (image or font)
- Minify JS/CSS files in assets/

Write your changes directly to the files. Return when done.
